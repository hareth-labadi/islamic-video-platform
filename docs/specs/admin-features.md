# لوحة الإدارة — كامل الميزات (بالدارجة)

هاد الملف فيه كل واش تدير لوحة الإدارة تاع الشيخ (`/ar/admin` و `/fr/admin`).
كل ميزة عندها رقم: إذا حبيتو تبدّلو حاجة، اكتبوها في خانة **«نبدّلوها؟»** ولا قولو الرقم برك (مثلاً «5.3»).

باش تجرّبوها: `npm run dev` ومن بعد `http://localhost:3000/ar/admin` — اختارو حساب تجريبي وأي 6 أرقام كـ code.
الشرح التقني للباك-آند راهو في [`admin-api.md`](admin-api.md).

**الأدوار:** **الشيخ** (مول الصفحة) · **أدمين** · **محرّر**. «الكل» = التلاتة.
